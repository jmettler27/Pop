1. Run `npm run update-i18n`. It extracts every `defineMessages('ns', { key: 'English' })` string into
   `src/i18n/locale/en.json` and re-orders `fr.json` to the same key order, inserting `""` for
   keys that have no French yet.
2. Read the script output. It reports **keys added to `fr.json` needing translation** and **stale `fr` keys
   not in source**.
3. For each empty (`""`) French value in `src/i18n/locale/fr.json`, propose an idiomatic French
   translation — match the tone, casing, and ICU placeholders (`{name}`, `{count, plural, …}`) of neighbouring
   entries — and apply it. Flag anything ambiguous instead of guessing.
4. Leave stale-key removal to me unless I say otherwise; just list them.
5. Summarize: N keys added, N translated, N left for review, N stale.
